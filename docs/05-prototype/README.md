# Prototype

The [prototype brief](./prototype-brief.md) illustrates the current terminal
preview, import, and JSON outcomes for people and terminal-capable agents.
DevWorkWire has no graphical interface or current MCP server. Older design
transcripts for updates, drift choices, and MCP tool calls are superseded by
[ADR-011](../04-decisions/adr-011-cli-first-agent-integration.md).

The separate [design direction](./design-direction.md) records earlier visual
ideas and should be read as historical until revised against the current CLI.
